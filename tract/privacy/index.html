Tract — Privacy Policy

Last updated: 23 August 2026

Summary

Tract is private by default for health logs. Hydration, bathroom, bladder-training, and Kegel data stay on your device using Apple's on-device SwiftData framework. We do not run accounts, analytics SDKs, or ads.

When you use Find Toilet, Tract sends your precise coordinates to map and restroom data services so it can show nearby results. That happens only for the search you request and is not stored on Tract servers as a user profile.

If you submit optional toilet feedback, Tract also sends an anonymous device fingerprint (a random UUID, not your Apple ID) to Tract’s Supabase backend so votes can be rate-limited.

Data stored on your device

  • Health-related logs (water intake, bathroom visits, training schedules, Kegel sessions, urge events, streaks)
  • App preferences (daily water goal, reminders)
  • Optional toilet-search cache — a recent nearby results snapshot so Find Toilet can still show last-known pins if the network fails
  • Random feedback fingerprint (UUID) used only for abuse prevention

Location shared for Find Toilet

Precise latitude / longitude may be sent to:

  • Tract’s toilet lookup backend (Supabase Edge Function / public toilet cache)
  • OpenStreetMap Overpass API
  • Refuge Restrooms API (refugerestrooms.org)

Location is not sold, not used for advertising, and not used for tracking across other companies’ apps.

Anonymous feedback fingerprint (Device ID)

When you submit toilet availability feedback, Tract sends a random device identifier (UUID) with the vote to Tract’s Supabase backend. It is used only to prevent spam / duplicate voting, is not linked to your name or Apple ID, and is not used for advertising or tracking across other companies’ apps.

Data we don't collect

  • We do not run Tract user accounts or sign-in.
  • We do not embed third-party advertising or analytics SDKs.
  • We do not sell personal data.

Subscriptions

Tract+ purchases are processed by Apple via StoreKit. Apple’s privacy policy governs payment information.

Your control

Delete local data anytime from Settings → Delete All Data. Uninstalling the app removes local data as well (including the feedback fingerprint).

Children

Tract is not directed at children under 13.

Changes

If this policy changes materially we will update the “Last updated” date above. Continued use of the app indicates acceptance of the updated policy.
